# AI 组件

面向大模型交互的界面能力，对应源码包 `@binarysovereign/bst-ai-components` 与主包 `@binarysovereign/vue-next-pro-ai`。

## 现状

本层组件尚在规划中，暂无已落地的组件与样式。规划方向包括：

| 组件 | 定位 |
| --- | --- |
| Bubble 气泡 | 承载单条对话内容的展示单元 |
| Sender 输入框 | 带发送、停止、附件等操作的消息输入区 |
| Conversations 会话列表 | 多会话的切换与管理 |

组件落地后，本页会替换为与[基础组件](/components/basic/)一致的组件列表。
