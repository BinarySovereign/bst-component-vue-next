# 样式预览

本页用于核对**设计令牌**的实际取值：改令牌后打开本页，就能确认新增项是否出现、明暗两套是否对齐。

::: warning 本页不是组件示例，也不含组件样式预览
站内的组件示例与样式预览一律以**真实组件**为准，不用原生标签拼出「看起来像」的效果。
组件尚未开发，站内没有可渲染的真实组件，因此本页**当前只覆盖令牌层**；组件样式预览会随组件落地一并补上。
:::

::: tip 前置条件
本页样式走 `@binarysovereign/styles` 的构建产物，首次启动前需要先产出样式：

```bash
pnpm build:style
```
:::

## 设计令牌

令牌清单由构建期插件从 `packages/bst-styles/web/tokens/*.less` 解析得到，**新增令牌会自动出现在下表**，无需手工维护。

- 分组默认折叠，筛选框一有输入即自动展开命中的分组；
- 色块以 `var(--bst-*)` 实时着色，因此会随站点主题同步切换；
- 右侧文本给出明暗两套的静态取值，`←` 之后的写法表示该令牌是另一个令牌的别名。

## 环境检查清单

本页所在的目标环境是 **Blink 单一引擎**（Chrome / Edge / Electron，见[浏览器支持](/guide/installation#浏览器支持)），
故「换浏览器再看一遍」没有意义。令牌层可核对的环境档位如下：

| 检查项 | 怎么触发 | 期望 |
| --- | --- | --- |
| 暗色主题 | 顶部导航的明暗开关 | 色块随主题变色；标注为「亮 / 暗」两套的令牌，实际取值与表格一致 |
| 页面缩放 | 浏览器缩放 100% / 125% / 150% / 200% | 表格不横向溢出、色块不被裁切 |
| 主题覆盖 | 在 DevTools 中改写 `:root` 上的某个 `--bst-*` | 对应色块实时跟随，验证令牌确实经由 `var()` 生效 |

### 关于引擎版本

目标集的下限是 **Chromium 148**（由 `Electron >= 42` 折算而来），比最新稳定版低若干档。
在更**新**的引擎上通过不代表在下限上也通过，反向则成立，因此严格验证应固定在 148 上做：

- 用目标版本的 Electron 应用打开本页；
- 或按 `AGENTS.md` 的说明核对 `browserslist` 与 `Electron → Chromium` 的折算关系后再选版本。

### 本页覆盖不到的

- **组件样式**：需等真实组件落地；本页不提供手工拼样式的预览。
- **静态定位与 JS 行为**：面板位置计算、键盘导航、事件顺序、焦点管理均属组件实现，样式层不表达。
- **视觉回归**：仓库当前没有截图基线，本页只提供人工核对入口。
