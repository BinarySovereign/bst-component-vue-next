# Context-Menu 上下文菜单样式说明

> 本文档从 `Ardot` 设计稿当中导出 `CSS` 样式，以下所有样式均为 `Light` 模式
>
> 根据此文档编写组件样式的时候，请仔细思考样式属性的选择

## 菜单根容器

### 布局

```css
width: 320px;
max-height: calc(100vh - 16px);
flex-shrink: 0;
display: flex;
padding-top: var(----bst-comp-padding-tb---bst-comp-padding-tb-xs, 4px);
padding-right: var(----bst-comp-padding-lr---bst-comp-padding-lr-xs, 4px);
padding-bottom: var(----bst-comp-padding-tb---bst-comp-padding-tb-xs, 4px);
padding-left: var(----bst-comp-padding-lr---bst-comp-padding-lr-xs, 4px);
flex-direction: column;
align-items: flex-start;
```

### 样式

```css
background: var(----bst-bg-color-container, #FFF);
border-radius: 6px;
/* Shadow/Light/Shadow-2 中层投影 */
box-shadow: var(----bst-shadow-2-offsetX-3, 0px) var(----bst-shadow-2-offsetY-3, 5px) var(----bst-shadow-2-blur-3, 5px) var(----bst-shadow-2-spread-3, -3px) rgba(0, 0, 0, 0.10), var(----bst-shadow-2-offsetX-2, 0px) var(----bst-shadow-2-offsetY-2, 8px) var(----bst-shadow-2-blur-2, 10px) var(----bst-shadow-2-spread-2, 1px) rgba(0, 0, 0, 0.06), var(----bst-shadow-2-offsetX-1, 0px) var(----bst-shadow-2-offsetY-1, 3px) var(----bst-shadow-2-blur-1, 14px) var(----bst-shadow-2-spread-1, 2px) rgba(0, 0, 0, 0.05);
```

## 菜单项根容器

- 菜单项根容器的宽度：占满 `菜单根容器` 宽度，即 `100%`

### 布局

```css
/** item */
height: var(----bst-size---bst-size-11, 36px);
flex-shrink: 0;
display: flex;
padding-right: var(----bst-comp-padding-lr---bst-comp-padding-lr-l, 16px);
padding-left: var(----bst-comp-padding-lr---bst-comp-padding-lr-l, 16px);
align-items: center;
gap: var(----bst-comp-margin---bst-comp-margin-s, 8px);

/** divider */
height: 1px;
flex-shrink: 0;
display: flex;
align-items: flex-start;
```

### 样式

```css
/** item */
background: var(----bst-bg-color-container, #FFF);

/** divider */
background: var(----bst-component-stroke, #E8E8E8);

/** item-hover */
background: var(----bst-bg-color-container-hover, #F3F3F3);
```
