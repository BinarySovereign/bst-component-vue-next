# 样式开发代码规范

> 所有文件命名均采用 `_` 前缀 + `k-b` 命名风格；类名、变量名与关键帧命名见各分片说明

本目录为新增组件样式的**纯骨架**：全部文件为空，命名规则与填写清单以本 README 为准。完整包级规范见 `packages/bst-styles/README.md`。

## 整体目录结构

```
{组件名}/
├── _index.less           # 组件样式聚合入口，按依赖方向 @import 各分片
├── _variables.less       # 组件级变量：--bst-<组件名>-<语义> 定义处
├── _token.less           # 组件级令牌映射：分片唯一引用面 @<组件名>-*
├── _root.less            # 根容器与排版基线
├── _element.less         # 子结构分片（示例文件，重命名为实际子结构后使用）
├── _state.less           # 交互与语义状态（跨子结构共享）
├── _size.less            # 尺寸变体
└── _animation.less       # 过渡与关键帧
```

> 未命中的分片直接删除，无需保留空文件。

---

## 文件说明

### `_index.less`（聚合入口）

- **作用**：按依赖方向聚合各分片，自身不承载任何选择器与声明。
- **约束**：
  1. `@import` 顺序固定：**组件变量 → 令牌映射 → 根容器 → 子结构 → 状态 → 尺寸 → 动画**。
  2. `mixins/_index.less` 只导出 `_clearfix` / `_text` / `_scrollbar` / `_layout` 四个分片；下列混入**未导出**，需要时须在分片内显式引入：
     - `.reset-base()` / `.reset()` → `@import '../../mixins/_reset.less';`
     - `.tab-focus-style-rect()` → `@import '../../mixins/_focus.less';`
  3. 分片与本入口同处一条编译链，故分片可引用 `_token.less` 暴露的 `@<组件名>-*`；**消费方不得单独导入某个分片**，否则变量未定义将编译失败。
  4. 在 `web/basic-components/_index.less` 中登记本入口：`@import './<组件名>/_index.less';`。
- **拆分决策**（阈值触发，满足其一即拆分；否则保留单文件 `_index.less`）：
  1. 单文件超过 150 行；
  2. 组件含 3 个以上独立子结构；
  3. 出现跨子结构复用的变量或混入；
  4. 同一组件存在尺寸 / 主题等多变体。

### `_variables.less`（组件级变量）

- **作用**：声明全局设计令牌无法表达、且需在运行时被外部覆盖的组件专有量。
- **约束**：
  1. 形态固定为 CSS 自定义属性，在 `:root` 内声明，命名 `--bst-<组件名>-<语义>`，不声明任何 `@` 变量。
  2. 分片不得直接以 `var()` 消费本文件，一律经 `_token.less` 映射为 `@<组件名>-*` 后引用。
  3. 全局令牌已覆盖的颜色、尺寸、圆角、投影、字体不在此重复定义。
  4. 无组件专有量时不建立本文件。
- **唯一消费方**：`_token.less`；删除本文件须同步移除 `_token.less` 中对应映射项。

### `_token.less`（组件级令牌映射）

- **作用**：组件样式的**唯一令牌命名面**，把两路来源按同一段序模板映射为 `@<组件名>-*`。
  1. 全局令牌：`tokens/_variables.less` 已映射的令牌，如 `@brand-color`、`@size-4`、`@text-color-primary`、`@bg-color-container-hover`；
  2. 组件专有量：`_variables.less` 声明的 `--bst-<组件名>-<语义>`，以 `var()` 包裹后纳入同一命名面。
- **命名段序**：`<组件名>-[<类型>]-[<场景>]-<属性>[-<状态>]`
  1. 组件名：kebab-case，不含 `bst-` 前缀，如 `context-menu`；
  2. 类型（限定段）：区分组件变体（如 button 的 `line`）或子结构元素（如 `item` / `mask`），无则省略；
  3. 场景：属性应用场景，如背景 `bg`、文本 `text`、边框 `border`，无则省略；
  4. 属性：如 `color`、`height`、`radius`；
  5. 状态：状态或尺寸档，如 `hover`、`disabled`、`s`、`l`。
- **约束**：
  1. 分片只允许引用本文件输出的 `@<组件名>-*`；全局令牌名与 `var(--bst-*)` 不得直接出现在分片中。
  2. 本层只做映射，既不产生新值也不做形态转换；来源 1 直接引用令牌名，来源 2 以 `var()` 引用 `_variables.less`。
  3. 来源 2 经 `var()` 保留运行时覆盖能力，代价是编译期不可参与算术运算；确需计算时改取来源 1 的令牌。
  4. 每项独占一行并附注释，标注来源（全局令牌名 / 组件专有量）与语义。
  5. 组件不引用任何令牌时可不建立本文件；一旦引用，本文件即为其唯一出口。
  6. 本文件须置于 `_variables.less` 之后，并与本组件 `_index.less` 处于同一条 `@import` 链。

### `_root.less`（根容器与排版基线）

- **作用**：声明组件根类的盒模型与排版基线，以及仅作用于根层的定位、层叠与溢出规则。
- **类名**：根类固定 `.@{prefix}-<组件名>`，与组件 `defineOptions({ name })` 的 kebab-case 对应。
- **约束**：
  1. 盒模型与排版基线优先调用 `.reset-base()`，不手写 `box-sizing` / `color` / `font`。
  2. 令牌一律经 `_token.less` 的 `@<组件名>-*` 书写，不得出现硬编码值、全局令牌名与 `var(--bst-*)`。
  3. 状态修饰类不写在这里，统一收敛至 `_state.less`。
- **依赖提示**：本文件依赖 `_token.less`；若某项映射来源为组件专有量（`var(--bst-<组件名>-<语义>)`），须同时保留 `_variables.less`，否则该 `var()` 将悬空。
- **填写清单**：
  1. 基线：调用 `.reset-base()`；
  2. 布局：`display` 与 `flex-*` / `grid-*` 系列；
  3. 尺寸：高度取 `@<组件名>-height-*`；宽度优先取尺寸令牌阶梯，阶梯确实无对应项时才映射组件专有量；
  4. 边距：内边距取 `@<组件名>-padding-lr-*`，避免魔法数字；
  5. 视觉：圆角取 `@<组件名>-radius`，投影取映射后的投影令牌；
  6. 背景：取映射后的容器背景（来源 `@bg-color-container`；勿用 `@bg-color-page`，后者为页面级底色）；
  7. 文字：文字色与字体简写均取映射后的组合令牌；
  8. 溢出：声明 `overflow` / `overflow-y`，并说明滚动职责归属哪一层。

### `_element.less`（子结构分片）

- **作用**：承载「一个子结构」的全部布局：该结构自身的盒模型、排版与内部排布。
- **使用方式**：复制本文件并按实际子结构命名，如 `_item.less`（列表项）、`_list.less`（滚动区）、`_mask.less`（蒙层）；一个文件只承载一个子结构，子结构之间不共享规则，公共部分上提至 `_root.less`。
- **类名**：`.@{prefix}-<组件名>-<元素>`，元素名以单连字符连接，禁用 `__` 与 `--` 分隔符。
- **约束**：
  1. 嵌套深度不超过 3 层。
  2. 令牌一律经 `_token.less` 的 `@<组件名>-*` 书写，不得直接写全局令牌名。
  3. 仅作用于本子结构的悬浮、聚焦等就近反馈，可直接以 `&` 嵌套表达；会被多个子结构共享的状态写入 `_state.less`。
- **填写清单**：
  1. 布局：`display` / `align-items` / `gap` 系列，间距取 `@<组件名>-gap` 一类；
  2. 尺寸：高度取 `@<组件名>-height-*`，内边距取 `@<组件名>-padding-lr-*`，上下为 0 时高度已由 `height` 固定；
  3. 文字：文字色与字体均取映射后的组合令牌；
  4. 交互：`cursor` 按可操作性声明，需禁止拖选时补 `user-select`；
  5. 截断：单行省略调用 `.text-ellipsis()`，多行调用 `.text-ellipsis-multi-line(<行数>)`，调用前确保该元素在弹性布局下具备收缩能力（如 `min-width: 0`）；
  6. 弹性收缩：位于 column 容器内的恒高子项须显式声明 `flex: none`，避免被等比压缩；
  7. 就近悬浮态：以 `&:hover` 嵌套，背景取映射后的容器悬浮背景色。

### `_state.less`（交互与语义状态）

- **作用**：收敛「跨子结构共享」的状态修饰类。
- **命名**：统一 `.bst-<组件名>[-<元素>]-is-<状态>`，状态词取英文形容词：`is-disabled` / `is-selected` / `is-active` / `is-loading` / `is-expanded` …
- **边界**：
  1. 仅作用于单一子结构的就近反馈，写在该子结构分片内，不进本文件。
  2. 本文件只承载被多个子结构共享、或语义上属于组件级的状态。
  3. 状态色一律取映射后的语义令牌，不出现硬编码色值与主题分支。
  4. 排列顺序：先写单一修饰类，再写带后代的选择器，避免特异性倒置。
- **填写清单**：
  1. 禁用态 `.bst-<组件名>-is-disabled`：文字色映射 `@text-color-disabled`，指针取 `not-allowed`；子元素若自带颜色，须在同级以后代选择器显式覆盖为同一禁用色；
  2. 选中态 `.bst-<组件名>-is-selected`：背景映射 `@brand-color-light`，文字色需要时映射 `@text-color-brand`；
  3. 其余状态按语义补充：悬浮 → `@bg-color-container-hover`、按下 → `@bg-color-container-active`、组件禁用 → `@bg-color-component-disabled`，每项附注释说明语义。

### `_size.less`（尺寸变体）

- **作用**：承载由 `size` 一类属性驱动的尺寸变体，各变体只覆盖差异项。
- **命名**：变体类 `.bst-<组件名>-size-<档位>`，档位取自组件尺寸令牌阶梯：`xxxs / xxs / xs / s / m / l / xl / xxl / xxxl`。
- **约束**：
  1. 基线尺寸写在 `_root.less`，本文件只回答「相对基线改了什么」；
  2. 档位取值引用映射后的 `@<组件名>-*`，不写魔法数字、不直接写令牌名；
  3. 无尺寸变体的组件不建立本文件。
- **填写清单**：
  1. 高度：`@<组件名>-height-<档位>`；
  2. 内边距：`@<组件名>-padding-lr-<档位>`，与高度档位匹配；
  3. 字号与行高：需要随尺寸变化时取 `@<组件名>-font-<档位>`；
  4. 变体内若仍需覆盖其他属性，仅写差异项，其余继承 `_root.less` 的基线声明。

### `_animation.less`（过渡与关键帧）

- **作用**：集中声明组件的 `transition` 与 `@keyframes`，避免动画声明散落于各子结构分片。
- **命名**：关键帧统一 `bst-<组件名>-<语义>`。
- **约束**：
  1. 缓动与时长取 `_token.less` 中映射后的 `@<组件名>-anim-*`，不直接写全局令牌名；
  2. 须尊重 `prefers-reduced-motion`：系统声明减少动效时关闭非必要过渡；
  3. 无过渡与动画的组件不建立本文件。
- **填写清单**：
  1. 过渡：在目标选择器内声明 `transition`，多属性以逗号分隔、每项「属性 时长 缓动」，常见组合为 `color` 与 `background`，随主题切换平滑变化；
  2. 关键帧：`@keyframes bst-<组件名>-<语义>`，以 `to` 声明终态，旋转类用 `transform: rotate(<角度>)`；等速旋转直接写 `linear`，不套缓动令牌；
  3. 无障碍：`@media (prefers-reduced-motion: reduce)` 生效时将 `animation` 与 `transition` 置为 `none`；同一块内先写 `transition` 后写 `animation`。

## 标准开发流程

1. **复制模板**：复制 `template/` 为 `web/basic-components/<组件名>/`。
2. **删减分片**：删除本组件用不到的分片文件，保留的文件不必为空。
3. **定义变量**：`_variables.less` 声明组件专有量，无则删除该文件。
4. **映射令牌**：`_token.less` 按段序映射两路来源，逐项注释来源与语义。
5. **编写样式**：`_root.less` 写基线，子结构按需拆分为 `_<子结构>.less`，状态 / 尺寸 / 动画各归其位。
6. **聚合入口**：`_index.less` 按固定顺序 `@import` 保留的分片。
7. **登记入口**：在 `web/basic-components/_index.less` 中 `@import './<组件名>/_index.less';`。
8. **校验**：运行 stylelint 校验命名与书写规范。

## 强制约束清单

1. `_index.less` 只做聚合，自身不写选择器与声明；引用顺序固定为 变量 → 令牌 → 根 → 子结构 → 状态 → 尺寸 → 动画。
2. 分片只允许引用 `_token.less` 输出的 `@<组件名>-*`；全局令牌名与 `var(--bst-*)` 禁止出现在分片中。
3. `_variables.less` 只声明 `--bst-<组件名>-<语义>`，唯一消费方是 `_token.less`，分片不得直接 `var()` 消费。
4. 组件专有量必须经 `var()` 映射，以保留运行时覆盖能力。
5. 状态收敛：就近反馈留在子结构分片，跨子结构共享状态进 `_state.less`。
6. 各分片仅写差异项，基线统一在 `_root.less`。
7. 文件命名一律 `_` 前缀 + `k-b`；类名禁用 `__` 与 `--` 分隔符；不使用魔法数字与硬编码色值。

## 什么时候新增文件

1. 新增子结构 → 复制 `_element.less` 并重命名为 `_<子结构>.less`，在 `_index.less` 登记。
2. 出现跨子结构共享状态 → 新增 `_state.less`（已存在则追加）。
3. 组件出现尺寸变体 → 新增 `_size.less`。
4. 组件出现过渡 / 动画 → 新增 `_animation.less`。
5. 不创建空文件：无对应内容的分片不建立；已建立而无内容时删除，并同步移除其 `@import` 行。
